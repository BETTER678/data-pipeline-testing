# Curated Execution Evidence

This directory is a small, reviewable evidence package for the submission. The
full generated `reports/`, `data/processed/`, and `data/rejected/` trees are
machine-local and `.gitignore`d. Text and JSON files here are copied from a
successful run, converted to UTF-8, and sanitized so paths read `<project>` or
`<local>` instead of a developer's absolute path. The screenshot is a visual
rendering of `pytest_results.txt`; the text file remains canonical.

Provenance:

- generated by `.venv/Scripts/python.exe` on Windows 11, Python 3.13.15,
  pandas 2.3.3, NumPy 2.3.5, SQLAlchemy 2.0.44, Pandera 0.35.0;
- text and JSON evidence refreshed by `scripts/export_evidence.py`;
- all input data is synthetic; no secrets or customer data are present.

## Reproduce

From the project root, with the project virtual environment selected:

```powershell
.\.venv\Scripts\python.exe scripts\generate_data.py --preset small
.\.venv\Scripts\python.exe scripts\run_pipeline.py --run-id demo-small-001
.\.venv\Scripts\python.exe scripts\verify_outputs.py --run-id demo-small-001 `
  --output reports\verification_demo-small-001.json
.\.venv\Scripts\python.exe scripts\run_pipeline.py --run-id demo-small-002
.\.venv\Scripts\python.exe scripts\verify_outputs.py --run-id demo-small-002 `
  --output reports\verification_demo-small-002.json
.\.venv\Scripts\python.exe scripts\final_db_checks.py
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts\benchmark.py --pipeline --repeat 3
.\.venv\Scripts\python.exe scripts\export_evidence.py
```

`PARTIAL_SUCCESS` is expected for the curated demo: 37 deliberately invalid
source rows are quarantined. The exit code remains zero unless
`--fail-on-partial` is passed.
